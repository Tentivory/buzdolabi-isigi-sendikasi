# T.C. Buzdolabı Işığı Çalışanları Sendikası

**Kuruluş Yılı:** Kapı ilk kapanışından itibaren  
**Sicil No:** BD-ISIGI-2026-KAPALI  
**Statü:** Çok resmi. Çok ciddi. Hiç komik değil. (Komik.)

## 1. Amaç

Bu yazılım, buzdolabı içindeki ışığın **yalnızca kapı kapalıyken** mesai yaptığını, kapı açıldığında ise yasal greve çıktığını belgeleyen ulusal protokoldür.

Dışarıdan bakan vatandaş ışığın yandığını sanır. Sendika kaydına göre ışık **görünmediği için** çalışmaktadır. Görününce grev başlar. Bu, evrendeki en tutarlı iş hukukudur.

## 2. Kurulum

```bash
python3 buzdolabi_isigi_sendikasi.py
```

Bağımlılık yoktur. Çünkü ışık zaten evde vardır. Yazılım sadece tutanak tutar.

## 3. Kullanım

Program sizden kapının durumunu sorar:

- `kapali` → mesai, fazla mesai, kıdem, lojman hakkı  
- `acik` → grev, slogan, çay molası (buzdolabı içinde çay yoktur ama hak vardır)  
- başka bir şey → etik kurul toplanır, karar ertelenir
